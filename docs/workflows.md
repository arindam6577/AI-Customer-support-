# Workflow map

1. Ticket ingestion validates and registers a customer request.
2. AI classification returns category, priority, sentiment, confidence, summary, team, response, and duplicate probability.
3. Assignment selects the team and available agent.
4. Notification stores and delivers customer or agent communication.
5. SLA monitor checks open work every five minutes.
6. Escalation promotes critical, breached, or negative high-priority work.
7. Resolution feedback captures a rating and sentiment.
8. Analytics aggregates actual ticket data.
9. Daily report publishes the previous day’s observed KPIs.
